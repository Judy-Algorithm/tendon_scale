# 肌腱通道的缩放结果显示

每路显示同一参考姿势下的基准通路长度、个人通路长度和百分比变化。单位 mm；这些是整条 GeometryPath 的长度，不是肌纤维长度，也不是肌腱松弛长度，更不是个人肌腱的实测值。播放中的即时长度不参与此表。

`tendon-scale.js` 的基准长度于 2026-09-11 在计算服务器使用 OpenSim 4.5.2 提取：加载原始 XML，左手先执行 `repair_left_geometry`，初始化状态后读取各肌肉 `GeometryPath.getLength(state)`。读取时机与 `personalize.prepare` 中 `original_paths` 一致，在 `repair_wrap_domains` 之前。左右模型数值差小于 2e-16 m，按各自 SHA-256 严格匹配后共享常量；未匹配模板不显示数值。

现有缓存没有单独保存通路的参考长度，但是保存了最优肌纤维长度及肌腱松弛长度的缩放前后值。仅在计划声明 `Final/reference path ratio from immutable base; replace intermediate Scale result` 时，以肌纤维长度的前后比值还原最终通路长度，并检查肌腱松弛长度的比值一致。公式：个人参考通路长度 = 原始参考通路长度 × 已记录的最终/原始比例。绝不使用肌纤维长度与松弛长度之和代替通路长度。

此显示包含骨段缩放、掌部位置调整及当前路径修正的最终综合结果，不把它解释为单个骨段的缩放系数。参考长度几乎不变的通道标记为“长度不变”，其路径在运动时仍可能变化。关节范围检查中的非有限值或力臂跳变按通道标记“需复核”；其余“已缩放”只表示应用了几何调整，不认证解剖或动力学正确性。

数据取自当前加载结果并按肌肉名称匹配，切换样本或左右手时重新生成。缺数据、模板变化或前后比值不一致时显示“暂无对应的缩放结果”，不填零，不借用其他样本。保留通道显示开关、默认视频相机和鼠标旋转；“视频视角”按钮用于恢复与视频对应的相机，不改变播放进度。
