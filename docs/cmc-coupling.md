# 第4、5掌骨 CMC 联动示意

新增项由 control-data.js 独立组合进控制面板，原 atlas-data.js 的 16 个关节、23 个自由度及中立位肌腱关联不变。面板现在有 17 个控制组、24 个控制自由度、48 个动作按钮；新增控制组代表两个联动的腕掌关节。

## 几何与角度

- 原 MyoHand 网格中没有 CMC4/CMC5 原生关节轴。各掌骨的示意支点取其最靠近手腕的 3 mm 顶点带均值；不是经分割或实验识别的关节中心。
- 各支点至同指 MCP 中心定义掌骨长轴；与模型掌侧方向（+X）叉乘得到屈曲示意轴。此项只有掌侧屈曲，未重建完整三维对掌、旋前或骨面滚滑。
- 滑块角度 q 为第5掌骨角度，第4掌骨为 0.5q；q 范围为 0–20°。10°/20°和固定比例仅用于演示，不是个体实测或通用正常 ROM。
- 两掌骨绕各自基部同步转动，分别带动全部下游指骨；不会把手指 MCP 弯曲冒充 CMC 运动。切换关节与回中立位恢复静止几何。
- 第4、5掌骨的运动幅度不同且可用单一广义坐标表达掌弓形成，已有研究采用这一建模思路；本页面未复现其 CT 配准、三维转轴和拟合参数：[Buffi 等的 CMC 建模研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC3788642/)。
- 新项没有原始 CMC 力臂数据，因此不把指屈肌/伸肌的 MCP 关联复制为 CMC 驱动关系。界面明确显示 CMC 肌腱关联尚未配置。原37条通路仍在各原有关节中可用。

## 光学动捕标记

是否贴 CMC5 点取决于所选方案。有手部表面标记方案在第2、第5掌骨基部附近设置 CMC2、CMC5 标记，用二者中点形成虚拟标记，再与 MCP2–MCP5 标记建立不同手背平面；尺侧手平面使用 MCP4、MCP5，可描述掌弓变化。[Metcalf 等研究](https://eprints.soton.ac.uk/272224/1/MetcalfIEEETBME201158512241231.pdf)

单个点的位置轨迹本身不能唯一确定骨段三维姿态或两个独立 CMC 角度；还需同方案的参考点、骨段/关节定义与标定。这里的几何示意轴不是 marker 点，页面不新增虚构的实测动捕数据。
