# Tendon Scale：OpenSim 手部个体化缩放与运动展示

本仓库主要入口为 `http://127.0.0.1:4173/?mode=personal`。包含个人手部网站、三维关键点读取、左右手 OpenSim 内存缩放、动作拟合、肌腱通路导出及同步视频对比。

## 个人缩放模式

- 缩放规则：`server/scaling_core.py`、`palm_scaling.py`、`landmark_estimates.py`。
- OpenSim 执行与动作拟合：`server/personalize.py`，基于指定的 43 肌肉开发模型；不是 37 肌肉动力学/QP 流程。
- 数据入口：`server/extract_rrd.py` 读取 Rerun RRD 的 `/data/wilor/source/frames`，要求双手 21 点、有效标记和采集时间。当前未找到单独的 Chord 格式适配器；只有满足本文数据契约的导出才能使用，不能宣称支持任意 Chord 数据。
- 浏览器：`personal.js`、`video-sync.js`、`tendon-scale.js`，支持记录搜索、左右手切换、视频视角、停止等待以及逐通道缩放结果。
- 只保存轻量缩放方案及显示缓存，不为每人永久保存一份 XML。

同事接手请先看 [交接说明](docs/HANDOFF.md)，完整安装、数据字段与缩放边界见 [缩放与运行指南](docs/scaling-runtime.md)。左右手基准 `.osim` 和 33 份配套几何已放在 [models/base](models/base)，保留原文件及其使用限制，详见 [模型说明](models/README.md)。运行 `python3 scripts/setup-models.py` 可校验基准。

当前数据入口是服务器指定目录，尚未实现网页文件上传按钮和上传接口。原始 RRD、视频、个人结果及 SSH 凭据不在仓库中，需自行准备有权使用的数据及运行环境。

## 保留的旧版演示

以下说明仅适用于根路径 `/` 的历史演示，不适用于 `?mode=personal` 的实际 OpenSim 缩放流程。

ROM 动作与肌腱通路控制面板：原 16 个关节、23 个自由度、46 个方向按钮，另加第4、5掌骨 CMC 联动示意（1 个控制组、2 个方向按钮）。展开关节并点击动作，同时显示关联肌腱、转动对应骨骼及下游指骨。用 Display / Hide 控制路径和箭头；支持暂停、重播、回中立位、角度拖动和斜视／掌侧／侧面观察。鼠标拖动旋转，滚轮缩放。

鼠标悬停在骨头上时，只在鼠标旁显示该骨头的完整中文名称；移开、拖动或按 Esc 时隐藏。不再按展开关节常驻显示多条骨名和引线。识别覆盖全部 29 个骨骼网格，不受当前关节限制，并随旋转、缩放及 ROM 动作重新判断；被前景骨头或肌腱遮挡的骨头不显示名称。原肌腱标注与桡侧／尺侧方位提示保留。

画面在手腕附近用小字和细箭头标出桡侧（拇指侧）、尺侧（小指侧）。方位锚点位于桡骨、尺骨远端两侧，随视角变化；窄屏简写为「桡侧」「尺侧」以贴近手腕，标签避让当前骨名、肌腱名称和底部视角按钮；所有关节收起时仍可辨认手的方位。

## 运行

```sh
npm start
```

打开 http://127.0.0.1:4173。纯静态网站，无构建步骤、CDN 或服务器依赖。部署 Vercel 时选择 Other，构建命令与输出目录留空。

## 数据

- 骨骼网格和原始肌腱路径保留自 [EMG2Tendon](https://github.com/Judy-Algorithm/EMG2Tendon) 的公开 MyoHand 可视化，未替换为公司手部网格。显示时使用独立的局部附着修正数据；范围、依据和局限见 [附着核对](docs/attachment-review.md)。
- 右侧是用户指定的 SHM OpenSim 中立位控制表：16 个物理关节、23 个自由度、37 条启用通路，关联阈值为力臂绝对值 0.01 mm。
- 两者按通路 ID 连接。左侧依据 MyoHand 关节锚点、转轴及骨骼层级做几何运动示意，不是右侧 SHM 参数的配准结果；不使用原网站的教学仿真矩阵，也不是肌力驱动的动力学仿真。
- 原 MyoHand 含前臂旋转坐标、无独立拇指 MCP 侧向坐标。SHM 表含拇指 MCP 侧向自由度、不含前臂旋转；侧向项标注借用拇指 MCP 位置。PT、PQ 不列入活动执行器。
- 正负力臂转换为具体动作，而不是统一解释为屈曲／伸展。拇指 CMC 屈伸坐标正向为伸展；无名指、小指 MCP 侧向正向为内收；中指侧向使用桡偏／尺偏。范围沿用该表，不能解释为公开 MyoHand 的原生运动限位。
- 所有动作关联均为中立位结果，不代表全姿态的固定解剖功能或独立可控性。
- 通路名称下明确区分「起止位置（解剖参考）」和模型端点说明：前者来自 `attachment-reference.js`，给出对应解剖结构，不宣称与左图端点精确配准；UI_UB5 仅描述经 XML 确认的模型坐标系，未对应为真实小指尺侧骨间肌。`attachment-catalog.js` 和附着审计保留原几何分类，原 SHM 映射独立存于 `endpoint-data.js`。
- 第二轮逐一记录全部 74 个端点：40 个骨面拟合，34 个明确分类的例外；具体未解决问题见 [附着核对](docs/attachment-review.md)。仅为中立位可视化修正，未重做解剖标志点分割或力学验证。

## ROM 动作示意

- 每次只演示一个选定自由度；下游骨骼随父关节作刚体转动，切换动作会重置其他关节。
- PIP／DIP 伸展从 65% 预屈曲位置回到 0°，避免从中立位开始时看不出运动。
- 拇指轴正负方向按页面的动作约定转换；原模型缺失的拇指 MCP 外展／内收轴由屈曲轴和指骨方向构造，界面标注为补充示意轴。
- 肌腱线路随关节平滑变形，保留中立位附着修正和圆形端帽。该近似不求解肌力、肌腹收缩、骨面碰撞或通用多关节耦合；中立位肌腱关联不等于任意姿态下的驱动力关系。
- 第4、5掌骨 CMC 使用两个独立基部示意轴、一个联动滑块：第4掌骨转动滑块角度的一半，第5掌骨转动完整角度；示意上限分别为 10°、20°。掌骨携带各自整根手指，不额外弯曲 MCP/PIP/DIP。原始 SHM 表与网格保持不变；该新增项未配置驱动肌腱。参数来源和局限见 [CMC 联动说明](docs/cmc-coupling.md)。
- 页面默认展示中指 MCP 弯曲；启用系统减少动态效果时等待手动播放。

模型摘要及坐标方向约定见 `docs/data-provenance.json`。仓库不包含 EMG、录制数据、模型权重、服务器信息或认证凭据。
